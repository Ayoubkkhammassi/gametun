# 🎨 GameTun TCG — Prompts d'illustrations

**Comment faire :**
1. Utilise un générateur gratuit : **Bing / Copilot Image Creator**, **Leonardo.ai** (free), **Playground.ai**, **Ideogram**…
2. Format conseillé : **portrait 3:4** (vertical). Pas de texte sur l'image.
3. Colle le **STYLE DE BASE** + le prompt de la carte.
4. Enregistre chaque image avec **le nom de fichier exact** indiqué (ex. `recrue_braise.jpg`).
5. Envoie-moi les images → je les branche dans le jeu.

---

## 🧩 STYLE DE BASE (à mettre AVANT chaque prompt)

```
digital painting, dark fantasy game card art, neon glow, dramatic rim lighting,
cinematic, highly detailed, vertical portrait composition, centered subject,
epic mood, no text, no logo, no border, clean background focus
```
